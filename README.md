# 🌐 Pulse Browser

> Лёгкий, быстрый и приватный десктопный браузер на Electron.
> Тёмная тема Graphite, кастомный UI, защита отпечатка и поддержка прокси.

---

## ✨ Возможности

- 🎨 **Кастомный UI** — тёмная тема Graphite, вкладки, прогресс-бар загрузки, автодополнение адресной строки.
- 🖼️ **Иконки из PNG** — просто закинь свои в папку `icons/`.
- 🔒 **Stealth-режим** — подмена `navigator`, Canvas, WebGL и Audio fingerprint.
- 🌐 **Смена IP** — поддержка SOCKS5 и HTTP-прокси прямо из браузера.
- 🚫 **WebRTC защита** — блокировка утечки реального IP.
- 🏠 **Стартовая страница** — часы, дата, быстрые ссылки.
- ⌨️ **Хоткеи** — Ctrl+T, Ctrl+W, Ctrl+L, Ctrl+R, Alt+←/→.
